## 1.2.1 beta 1

This is a beta. It is a prerelease: installed copies are not offered it as an update, so download it from this page to try it.

### Catppuccin themes

- Choosing **Catppuccin** in Settings → Theme now also switches the mode to **Studio** and turns **Dynamic color** off. In Atmosphere, the album-art background and glass covered the palette, and album-art colours replaced the flavor's accent.
- Changing the flavor afterwards leaves the mode and Dynamic color as they are, and you can still turn either back on.
